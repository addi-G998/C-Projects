## CHIP8 Emulator

CHIP8 ROM games: [kripod/chip8-roms](https://github.com/kripod/chip8-roms/tree/master/games)

### Setup
Run `make install-deps` to install the SDL2 library.
> **Windows:** SDL2 must be installed separately from [libsdl.org](https://libsdl.org)

### Usage
```bash
make
./chip8Emu game.ch8
```
